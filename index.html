¿Cómo se Juega?

1 🔑 ID Principal

Es el identificador único de cada registro en la tabla principal (ejemplo: id_cliente, id_curso).

2 🔗 ID Enlace

Es el campo correspondiente en la otra tabla que hace referencia al ID Principal para vincular ambos registros.

🎮 2 Formas Sencillas de Conectar:
  • Arrastra desde la fila o círculo dorado hacia la fila o círculo violeta.
  • O Toca una fila para seleccionarla y luego toca la fila destino en la otra tabla.

¿Qué es el Ciclo de Vida del Software (SDLC)?

El SDLC (Software Development Life Cycle) es el marco metodológico utilizado por ingenieros y empresas tecnológicas de todo el mundo para planificar, diseñar, programar, probar y desplegar software de alta calidad sin desperdiciar recursos ni cometer errores costosos.

1

📋 Planificación

Se define el objetivo del negocio, la viabilidad técnica, el presupuesto y los plazos generales.

2

🔍 Análisis de Requisitos

Se recopilan historias de usuario y especificaciones funcionales exactas de los clientes.

3

📐 Diseño del Sistema

Se crean los planos: arquitectura técnica, modelo de datos relacional y prototipos UI/UX.

4

💻 Implementación

Los desarrolladores programan el código real, frontend, backend y lógica de negocio.

5

🧪 Pruebas y QA

Se cazan bugs, se ejecutan pruebas unitarias y de estrés para garantizar la estabilidad.

6

🚀 Despliegue y Soporte

El software sale a servidores de producción (CI/CD) y se monitorea y actualiza continuamente.
