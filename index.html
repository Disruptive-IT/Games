❓

¿Cómo se Juega?

1 🔑 ID Principal

Es el identificador único de cada registro en la tabla principal (ejemplo: id_cliente, id_curso).

2 🔗 ID de Enlace

Es el campo correspondiente en la otra tabla que hace referencia al ID Principal para vincular ambos registros.

🎮 2 Formas Sencillas de Conectar:
  • Arrastra desde la fila o círculo dorado hacia la fila o círculo violeta.
  • O Toca una fila para seleccionarla y luego toca la fila destino en la otra tabla.
